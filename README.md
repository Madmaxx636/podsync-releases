# PodSync releases

Installers and APKs for [PodSync](https://github.com/Madmaxx636/podsync), a podcast app for Windows, Linux and Android that syncs through your own server. The app checks this page for updates.

- `PodSync-Setup-x64.exe`: Windows installer (per-user, no admin rights needed)
- `PodSync-android.apk`: Android (ARM and x86_64)
- `SHA256SUMS.txt`: checksums for the files above
